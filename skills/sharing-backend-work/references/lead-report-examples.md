# C. 리드 보고

[전체 템플릿](case-templates.md) · [공통 작성 규칙](../SKILL.md)

멘션과 함께 전체를 코드펜스로 감쌉니다.

```
결론: {한 줄 판정}

### 증거 체인
1. {데이터 출처}: {조회 대상과 수치, 시각}
2. {로그 출처}: {추적 경로와 순서}
3. 트리거: {선행 사건과 수치}

### 배제된 것
- {가설}: {반증 근거와 수치}
- {가설}: {반증 근거와 수치}

### 해석
- {증거가 가리키는 의미}
- 서비스 영향: {있음/없음과 근거}

### 권장 대응
1. {근본 해결} — 권장
2. {임시 조치} — 1번 적용 전까지

조사 중 {쓰기 작업 여부}.
```

`배제된 것`은 리드가 "다른 원인일 수도 있지 않나"라고 되묻는 상황을 미리 막습니다.
`권장 대응`은 나열이 아니라 순위입니다. 어느 쪽을 권하는지 반드시 밝힙니다.
