# 계획 검토 기록

## 1차: 수정 요청

- 계획 검토 renderer는 URL 안의 홈 경로도 기존 정책으로 가린다. 새 정규화의 URL 보존을 기존 렌더 결과에 대한 추가 변형 금지로 한정하고 두 기대값을 분리해야 한다.

## 2차: 통과

- 기존 계획 검토 렌더러의 URL 가림과 신규 정규화의 URL 보존이 충돌하는지 다시 확인했다. 신규 함수에 들어온 URL 바이트를 보존하고 기존 렌더러가 이미 가린 결과는 유지한다고 경계를 명시했으며 두 동작의 검증도 나누어 모순이 해소됐다. 공개 파생 경계 하나와 원본 불변·반복 no-op·외부 계획 보호를 재사용한다.
