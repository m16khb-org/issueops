## I1 — Trace JSONL completeness and errors

**Observed defect.** `internal/adapter/trace/decode.go:26-37` uses the default bounded `bufio.Scanner`, skips every line whose JSON unmarshal fails, and returns without checking `scanner.Err()`. A token over Scanner's limit therefore stops the loop and discards later records. `internal/domain/trace/analysis.go:24-27` reports `JSONError` only when no findings were recovered; thus a malformed line followed or preceded by valid findings is silent. `internal/application/trace/service.go:59-66` always returns `OK=true` after analysis. Existing `TraceAnalyzeResult.Warnings` is already public (`internal/contract/trace/types.go:13-22`).

**Decision.** Keep Scanner bounded; do not raise its cap speculatively or change ingestion. Add one public `complete` boolean to `TraceAnalyzeResult`; retain `ok` as “analysis request ran.” Set `complete=false` for any malformed nonblank JSONL record or scanner error, including when valid findings were recovered. Reuse `warnings` with stable, input-free reason codes (for example `invalid_jsonl_line` and `jsonl_scan_error`); do not expose parser text, line contents, or arbitrary scanner error text. Keep ordinary valid JSON and valid JSONL complete. No skipped-line counter is needed for the minimum contract. The single-JSON parse failure that triggers JSONL fallback is not itself an incomplete-input warning if the JSONL records all parse.

**Ownership.** I1 owns `internal/adapter/trace/decode.go`, `internal/domain/trace/{observation.go,analysis.go}`, `internal/application/trace/service.go`, `internal/contract/trace/types.go`, `internal/adapter/trace/analyze_test.go`, and `internal/domain/trace/analysis_test.go`. Decoder records safe incompleteness reasons; domain analysis preserves them regardless of findings; service maps completeness and warnings to the response. Keep the change out of unrelated trace sources and finding logic.

**Tests / commands.** Add an adapter regression with a large valid JSONL row between two failed `step_end` sentinel rows; assert incomplete plus warning, and assert the trailing sentinel is not presented as a complete analysis. Add malformed-line tests both with and without valid findings; assert incompleteness remains visible with findings. Add a valid control. RED: `go test ./internal/adapter/trace -run '^TestTraceAnalyzeJSONLCompleteness$' -count=1` (new assertions fail against current behavior). GREEN: `go test ./internal/adapter/trace ./internal/domain/trace ./internal/application/trace -count=1`. Existing malformed-line fallback expectations in `analyze_test.go:153-177` must remain valid.
