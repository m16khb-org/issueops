## 지표와 계산 방법

[계산 결과](metrics.json)는 [verify.py](verify.py)로 재현한다. 원래 조사 스크립트와 산식은 보존된 저장소 자료에서 찾지 못했다. 따라서 **공개 기술에 맞춘 재구성 측정**이며, 동일 방법을 검증한 전후 비교가 아니다.

- H2 절 수는 `artifacttemplate.bodySections`와 같이 trim한 줄의 `## `를 세고, ``` 또는 ~~~로 시작하는 fence를 만날 때 상태를 전환한다. H1과 코드 안 H2는 제외한다.
- 문자 수는 제목을 제외한 본문 전체의 Unicode code point 수다. 줄바꿈·주석·코드를 포함하며 바이트 수나 화면상 글자 수와 다르다.
- 용어는 대소문자를 구별하는 substring 횟수이며 코드·명령을 포함한다. 네 열은 execution, lease, 봉인, generation 순이다.
- 64자리 hex는 `artifactreadability.blankCode`처럼 triple-backtick 블록과 inline code를 제외하고 Unicode 단어 경계로 센다. 이 규칙은 ~~~ 블록을 별도로 지우지 않는다. 이번 본문에는 ~~~ fence가 없다.
- 완료 구간은 start/end HTML marker를 포함한 문자 수를 보조 지표로 센다. 이전 네 이슈와 표본·시점이 다르며 정확한 증감 비교에 쓰지 않는다.

## 결정과 재현

[ADR](../../../.issueops/ADR.md)은 독자 검토를 권장 절차로 유지한다. 용어 설명과 완료 상태의 모호함을 찾는 데 쓰되, 단일 모델의 지적만으로 게시를 막는 필수 게이트를 추가하지 않는다. 원래 의도 unknown 3건, 반복 표본, 대조군 부재와 원래 산식 부재 때문에 의무화 비용 대비 효과를 확정할 근거가 부족하다. 필수화가 필요해지면 인간 독자·실제 수정 전후·오탐·소요 시간을 갖춘 별도 연구로 판단한다.

```bash
python3 docs/research/2026-09-30-readability/verify.py snapshot
python3 docs/research/2026-09-30-readability/verify.py metrics
python3 docs/research/2026-09-30-readability/verify.py evidence
```
